# Web App Idea Factory (Template)

このリポジトリは、アイディアを最小操作で Web アプリケーションとして形にするためのテンプレートです。

目的：
・アイディアを簡単・スピーディに Web アプリケーションにする
・PR ベースで安全に開発を進める
・codex を用いた実装を前提とする

前提：
・GitHub + Vercel を利用する
・main ブランチは常に本番として扱う

開発フロー概要：
1. アイディアを整理する
2. codex に実装を依頼する
3. Pull Request を確認して main にマージする
4. Vercel により自動デプロイされる

ブランチ運用：
・main：本番
・codex/<slug>：作業ブランチ

## 10クリック速度測定アプリ

`index.html` をブラウザで開くと、10回クリック（タップ）の速度を測定できます。

### 使い方
1. 大きなボタンを1回押すと計測開始
2. 10回目で計測終了
3. 合計時間（ms/秒）、CPS、平均間隔を表示
4. 「リトライ」で初期化
5. 直近5件の結果を localStorage (`clickSpeed10History`) に保存
